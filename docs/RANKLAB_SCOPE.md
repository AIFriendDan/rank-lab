# Rank Lab Scope

Rank Lab is an experimental, non-production HCiHY website laboratory.

## Objective

Explore whether stronger interaction design, scrollytelling, specificity, proof architecture, launch quality, and visual memorability can improve Website Launches competitiveness.

## Boundary

- This repository is not `hcihytech.com` production.
- No Rank Lab change is production-approved by default.
- Production migration requires explicit authorization and a separate review.

## Current experimental direction

**Bring Me the Mess**

A visitor experiences a business/technology mess being decomposed through scroll:

symptom → friction → root cause → system → outcome

The target memory is:

> It's the site where the tech mess untangles itself while you scroll.
